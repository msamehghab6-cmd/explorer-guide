EXPLORER'S GUIDE | AMS ENCYCLOPEDIA FOR STUDENTS

FILES
- index.html: website structure
- style.css: responsive visual design
- data.js: bilingual encyclopedia topic database (includes the saved original 106 topics and the expanded topic bank)
- script.js: search, subject filters, topic details, random topic, language switch, and learning links

RUN OFFLINE
1. Keep all four files in the same folder.
2. Double-click index.html to open it in a browser.
3. Search, filter, open topic details, and switch English/Arabic without internet.
4. Video and Wikipedia buttons require internet because they open external sites.

PUBLISH ON GITHUB PAGES
Upload/replace index.html, style.css, data.js, and script.js in the same GitHub Pages branch/folder. Commit the changes, then refresh the published website. Keep a backup of the old files before replacing them.

NOTE
The topic database preserves the original saved topic records and adds new bilingual entries. Some of the newly added entries use a general subject-learning explanation as a starter rather than a fully researched article, so the next content pass should deepen those topic-by-topic. External fonts and libraries are not required.
